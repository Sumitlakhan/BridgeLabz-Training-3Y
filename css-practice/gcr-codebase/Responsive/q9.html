Responsive Design Principles

Fluid Layouts

Fluid layouts use flexible units so that content can adjust to different screen sizes. 

.container {
    width: 90%;
}

Flexible Media

Flexible media allows images and videos to resize according to the available space. 

img {
    max-width: 100%;
}

Breakpoints

Breakpoints allow CSS to change when the screen reaches a particular width. 

@media (max-width: 600px) {
    ...
}

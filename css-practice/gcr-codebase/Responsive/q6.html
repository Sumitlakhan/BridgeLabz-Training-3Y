Responsive CSS Cheat Sheet

Important concepts of responsive web design

Filters

CSS filters can change the appearance of images.

filter: grayscale(100%);

Media Queries

Media queries apply CSS according to screen size.

@media (max-width: 700px)

Responsive Design

Responsive design makes websites adapt to different screen sizes.

width: 100%;

Typography

Responsive typography changes text size according to the viewport.

font-size: clamp(1rem, 2vw, 2rem);

CSS Grid

Grid creates flexible rows and columns for layouts.

display: grid;

Flexbox

Flexbox is useful for arranging elements in rows or columns.

display: flex;

Responsive Design

Responsive web design allows a website to adjust automatically according to the device screen size.

CSS Grid, Flexbox, media queries and relative units help create responsive websites.

Cheat Sheet

Grid: Creates rows and columns.
Flexbox: Aligns elements easily.
Media Query: Changes CSS based on screen size.
